## 并行规则

第一批可并行执行 T1、T2、T3。T4 等待 T1/T2 的确定结果，T5 等待 T3/T4 及生产操作授权。
每个会话先检查 Git 状态和适用 AGENTS.md，保留他人修改。使用独立工作树时，注意未提交文档不会自动出现；由协调会话交付审阅副本或已提交基线。

每个任务只修改其独占文档。所有包源码、版本、生成资产和共用验收记录由协调会话控制；需要修复产品时先报告范围，再单独分配任务。
本清单的状态也只由协调会话更新。领取会话返回结果，不自行修改其他任务状态。
公开仓只使用 Host A/B 和 `/absolute/path/to/...` 等占位符；真实设备映射、凭据、配置备份和原始运行数据留在受保护的本地证据目录。
