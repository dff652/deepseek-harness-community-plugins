## 为什么现在设备信息未知

provider 的 `agentDetails` 当前返回 `device_name: null`、`device_ip: null`、
`connection: unknown`，没有心跳；身份目录登记不能证明在线。
Hub 地址在本地邮箱模式下不适用；最近观测并不是通用的收件人在线信息。
前端列表还硬编码了未知状态。UI 应诚实处理能力缺失，不能通过刷新、假 IP 或绿色圆点补齐。
设备登记和心跳属于 B1，不作为本次界面优化的前提。
